# 🐾 Боня · Сайт воспоминаний

Лендинг-страница в память о **Боне** — британской короткошёрстной кошке.
Тёплые истории, галерея настроений и хронология наших лучших моментов вместе.

## ✨ Возможности

- **Адаптивный лендинг** — корректно отображается на телефоне, планшете и десктопе.
- **Плавные анимации** — секции мягко появляются при прокрутке (IntersectionObserver).
- **Разделы:** о Боне, галерея настроений, хронология истории, тёплые воспоминания.
- **Без зависимостей** — чистые HTML, CSS и JavaScript, никакой сборки не требуется.

## 🗂️ Структура проекта

```
Memories/
├── index.html    # разметка лендинга
├── styles.css    # стили и адаптивная вёрстка
├── script.js     # анимации появления и логика
└── README.md     # документация проекта
```

## 🚀 Запуск локально

Проект статический — достаточно любого простого HTTP-сервера.

```bash
# вариант с Python 3
python3 -m http.server 8000 --bind 127.0.0.1
```

Затем открыть в браузере: <http://127.0.0.1:8000>

Либо просто открыть файл `index.html` двойным щелчком.

## 🛠️ Технологии

- HTML5 (семантическая разметка)
- CSS3 (Grid, Flexbox, кастомные свойства, анимации)
- Vanilla JavaScript (IntersectionObserver)
